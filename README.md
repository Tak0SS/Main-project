# Main-project
Это телеграмм-бот по глобальному потеплению. Бот тебе расскжет о нем, расскажет о влиянии глобального потепления на экосистему планеты, с каких пор и как оно произошло, интересные факты, а также что ты можешь сделать, чтобы уменьшить влияние глобального потепления.
PS: Этот проект создан для ознакомления с проблемой и не несет принудительного характера.
